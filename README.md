# 민원 연결의 神 (KIPI COMPLAINT MASTER)

한국특허정보원 사내 e-sports 행사용 민원 라우팅 게임입니다.
민원 내용을 읽고 담당 부서로 3분 안에 최대한 많이 연결하며, 플레이 과정에서
기관의 사업과 타 부서 업무를 자연스럽게 익히는 것을 목적으로 합니다.

## 실행

```bash
npm install
npm run dev      # 프론트 개발 서버 (http://localhost:5173)
npm run dev:api  # 백엔드 개발 서버 (http://localhost:8787)
npm run build    # shared + backend + frontend 빌드
npm test         # 서버 검증 로직 테스트
```

백엔드 없이도 게임은 돌아갑니다. 서버가 없으면 기록이 브라우저에만 남고
순위에는 반영되지 않는다고 화면에 표시됩니다.

### Docker

```bash
cp .env.example .env    # APP_SECRET · ADMIN_TOKEN · DB_PASSWORD 채우기
docker compose up -d    # http://localhost:8787
```

컨테이너 하나가 API와 프론트 정적 파일을 함께 서빙합니다.

## 구성

| 경로 | 설명 |
| --- | --- |
| `docs/PRD.md` | 제품 요구사항 정의서 v2 |
| `shared/src/rules.ts` | 게임 규칙 — 점수·페이즈·리플레이 채점 |
| `shared/src/round.ts` | 출제 계획 — 시드로 문항 시퀀스를 만든다 |
| `shared/src/data/` | 문항·분류 데이터 (엑셀에서 생성) |
| `backend/src/verify.ts` | 라운드 토큰과 제출 로그 검증 |
| `backend/src/routes.ts` | API |
| `frontend/src/game/useGame.ts` | 라운드 상태 머신 |
| `frontend/src/App.tsx` | 랜딩 / 게임 / 결과 화면 |
| `docs/문제은행_v4.xlsx` | 문제 은행 원본 — 문항 추가·수정은 여기서 |
| `scripts/import_bank.py` | 문제 은행 → 게임 데이터(TS) 생성 |
| `frontend/src/data/*.ts` | 생성물. 직접 고치지 말 것 |

`shared`가 프론트와 백엔드 양쪽에서 쓰이는 것이 설계의 핵심입니다.
클라이언트는 화면을 그리려고, 서버는 제출된 입력 로그를 재생해 점수를 다시
계산하려고 같은 함수를 씁니다(PRD 7장). 규칙을 고칠 때는 반드시 `shared`만
고쳐야 양쪽이 어긋나지 않습니다.

## 무결성

점수는 서버가 정합니다. 클라이언트는 "무엇을 눌렀는지"만 보고하고, 서버가
같은 규칙 엔진으로 다시 계산합니다. 실제로 확인한 결과:

| 시도 | 결과 |
| --- | --- |
| 점수 999999 전송 | 서버가 로그를 재생해 687점으로 확정 |
| 같은 토큰 재제출 | 409 `token_used` |
| 발급되지 않은 문항 제출 | 422 `sequence_mismatch` |
| 토큰 위조 | 401 `invalid_token` |
| 흐른 시간보다 오래 플레이했다고 주장 | 422 `impossible_timing` |

남는 한계는 매크로입니다. 통계적 이상 탐지(`fast_streak`, `robotic_timing`)로
운영자 검토 대상만 표시하며, **상품이 걸린 최종 순위는 현장 결승으로 결정하는
것을 권장합니다**(PRD 7.4).

## 문제 은행

`docs/문제은행_v4.xlsx`가 원본입니다. www.kipi.or.kr 주요사업·조직안내를 직접
열람해 작성했으며(조사일 2026-08-13), 문항마다 확인한 URL을 출처로 남겼습니다.

| 구분 | 수 |
| --- | --- |
| 엑셀 총 문항 | 200 |
| **게임 반영 (검수완료)** | **186** |
| 보류 — 사이트에서 확인 불가 | 14 |
| 게임 노출 분류 | 13 |

문항을 고친 뒤에는 다시 생성하십시오.

```bash
python3 scripts/import_bank.py    # 엑셀 → departments.ts / complaints.ts
```

`frontend/src/data/*.ts`는 생성물입니다. 직접 고치면 덮어써집니다.

### 게임에 넣는 기준

- 분류체계 시트의 `게임 노출`이 `노출`인 분류만
- `검수상태`가 `검수완료`인 문항만

보류 문항을 빼는 이유는 이 게임이 오답 시 해설을 그대로 띄워 참가자를
학습시키기 때문입니다. 확인되지 않은 내용을 가르치면 안 됩니다. 확인이 끝나
검수완료로 바꾸면 다음 생성 때 자동으로 합류합니다.
